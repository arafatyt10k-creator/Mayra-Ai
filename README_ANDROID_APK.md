# MAYRA AI — Android APK & Mobile Deployment Guide
(অ্যান্ড্রয়েড ফোনের জন্য সম্পূর্ণ ফ্রি এপিকে তৈরি ও ইনস্টল করার গাইড)

এই গাইডটি বিশেষভাবে তৈরি করা হয়েছে তাদের জন্য যাদের কোনো **কম্পিউটার বা পিসি নেই**, শুধু একটি **অ্যান্ড্রয়েড স্মার্টফোন** আছে।

---

## 📌 সারসংক্ষেপ ও বর্তমান স্ট্যাটাস (Honest Status)

1. **এই ক্লাউড কন্টেইনারে সরাসরি APK তৈরি হয়েছে কি?**  
   - **না।** AI Studio ওয়েব কন্টেইনারে `java`, `javac`, বা `android-sdk` ইনস্টল থাকে না (`which java` খালি)। তাই কন্টেইনারের ভেতর সরাসরি `.apk` কম্পাইল করা সম্ভব নয়।
   - তবে আপনার অ্যাপের **সম্পূর্ণ নেটিভ অ্যান্ড্রয়েড প্রজেক্ট (`/android`)**, **Capacitor 8**, **Gradle Wrapper (`gradlew`)**, এবং **স্বয়ংক্রিয় GitHub Actions ক্লাউড ওয়ার্কফ্লো (`.github/workflows/build-apk.yml`)** শতভাগ প্রস্তুত করে দেওয়া হয়েছে।

2. **মোবাইল থেকে কীভাবে সম্পূর্ণ ফ্রিতে আসল `.apk` পাবেন?**
   - **পদ্ধতি ১ (তাত্ক্ষণিক ও শূন্য ঝামেলা):** অ্যাপের ভেতর থেকে **১-ট্যাপ ইনস্টল (PWA Standalone WebAPK)** — সরাসরি হোমস্ক্রিনে চলে আসবে, ক্যামেরা, ফুল-স্ক্রিন, মাইক্রোফোন সব কাজ করবে।
   - **পদ্ধতি ২ (আসল .apk ফাইল তৈরি - ১০০% ফ্রি ক্লাউড বিল্ড):** GitHub Actions ব্যবহার করে মোবাইলের ব্রাউজার দিয়েই ২ মিনিটে আসল `app-debug.apk` বিল্ড করে ডাউনলোড করতে পারবেন।
   - **পদ্ধতি ৩ (Termux মোবাইল টার্মিনাল):** আপনার অ্যান্ড্রয়েড ফোনের ভেতরেই Termux অ্যাপ দিয়ে অফলাইনে `.apk` কম্পাইল করা।

## 🚀 পদ্ধতি ১: তাত্ক্ষণিক ১-ট্যাপ ইনস্টল (মোবাইল ব্রাউজার থেকে)

আপনার ফোনে কোনো ফাইল ডাউনলোড বা বিল্ড না করেই সবচেয়ে দ্রুত অ্যাপ হিসেবে পেতে:

1. আপনার ফোনের **Google Chrome** ব্রাউজারে MAYRA AI লিংকটি খুলুন।
2. অ্যাপের উপরের ডানপাশের **`📲 APK`** বাটনে চাপুন অথবা Chrome ব্রাউজারের উপরে ডান কোনায় থাকা **৩টি ডট মেনু (⋮)** চাপুন।
3. মেনু থেকে **"Install app"** বা **"Add to Home screen"** চাপুন।
4. সাথে সাথে আপনার ফোনের অ্যাপ ড্রয়ারে এবং হোম স্ক্রিনে **MAYRA AI** এর নিজস্ব আইকন চলে আসবে।
5. এটি সাধারণ ব্রাউজার ট্যাবের মতো নয় — এটি স্ট্যাটাস বার ঢেকে সম্পূর্ণ নেটিভ ফুল-স্ক্রিনে ওপেন হবে এবং ক্যামেরা ও মাইক্রোফোন পারমিশন সহ রিয়েল-টাইমে কাজ করবে।

## ⚡ পদ্ধতি ২: GitHub Actions দিয়ে সম্পূর্ণ ফ্রি আসল APK বিল্ড (ফোন থেকেই)

GitHub Actions প্রতি মাসে **২,০০০ মিনিট ফ্রি বিল্ড টাইম** দেয়। এর জন্য কোনো টাকা বা ক্রেডিট কার্ড লাগে না।

### ধাপ ১: প্রজেক্ট জিপ ডাউনলোড করুন
1. MAYRA AI অ্যাপটি ওপেন করুন।
2. উপরের **`📲 APK`** আইকন চাপুন এবং **"Export Source"** ট্যাবে যান।
3. **"Download Full Android Source ZIP"** চাপুন। আপনার ফোনের `Downloads` ফোল্ডারে `mayra-ai-android-project.zip` ফাইলটি সেভ হবে।

### ধাপ ২: মোবাইলে GitHub-এ রিপোজিটরি তৈরি করুন
1. ফোনের Chrome ব্রাউজারে [github.com](https://github.com) এ লগইন করুন।
2. নতুন একটি রিপোজিটরি তৈরি করুন, নাম দিন: `mayra-ai` (Public বা Private যেকোনোটি)।
3. রিপোজিটরির ভেতর **"upload files"** অপশনে গিয়ে আপনার জিপ ফাইলটি আনজিপ করে ফাইলগুলো আপলোড করুন (অথবা গিট দিয়ে পুশ করুন)।

### ধাপ ৩: ১-ট্যাপে APK বিল্ড শুরু করুন
1. আপনার রিপোজিটরির **"Actions"** ট্যাবে যান।
2. বামপাশে থাকা **"Build MAYRA AI Android APK"** ওয়ার্কফ্লোতে চাপুন।
3. **"Run workflow"** বাটনে ট্যাপ করুন।
4. GitHub-এর শক্তিশালী ক্লাউড সার্ভার স্বয়ংক্রিয়ভাবে:
   - Node.js ও Java 17 সেটআপ করবে।
   - Capacitor Android সিঙ্ক করবে।
   - Gradle দিয়ে আসল `app-debug.apk` বিল্ড করবে।
5. প্রায় **২ মিনিটের মধ্যে** বিল্ড সম্পন্ন হবে এবং পেজের নিচে **Artifacts** বা **Releases** সেকশনে `mayra-ai-debug-apk` / `app-debug.apk` ডাউনলোড লিংক দেখতে পাবেন।
6. লিংকে ট্যাপ করে সরাসরি আপনার ফোনে ডাউনলোড করুন এবং ইনস্টল করুন!

## 🛠 পদ্ধতি ৩: Termux দিয়ে ফোন থেকেই লোকাল APK বিল্ড

আপনি যদি কোনো ক্লাউড সার্ভিস ছাড়াও সম্পূর্ণ নিজের অ্যান্ড্রয়েড প্রসেসর ব্যবহার করে বিল্ড করতে চান:

1. F-Droid থেকে **Termux** অ্যাপ ইনস্টল করুন।
2. Termux ওপেন করে নিচের কমান্ডগুলো রান করুন:

```bash
# ১. প্রয়োজনীয় প্যাকেজ ইনস্টল
pkg update -y && pkg install -y openjdk-17 nodejs-lts git unzip

# ২. প্রজেক্ট এক্সট্রাক্ট করুন
unzip /sdcard/Download/mayra-ai-android-project.zip -d mayra-ai
cd mayra-ai

# ৩. ডিপেন্ডেন্সি ও বিল্ড
npm install
npm run build
npx cap sync android

# ৪. Gradle দিয়ে APK তৈরি
cd android
chmod +x gradlew
./gradlew assembleDebug

# ৫. তৈরি হওয়া APK ফোনের ডাউনলোড ফোল্ডারে পাঠানো
cp app/build/outputs/apk/debug/app-debug.apk /sdcard/Download/MAYRA-AI.apk
```
